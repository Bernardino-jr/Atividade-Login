# Atividade 1 - Tela de Login

Página de login desenvolvida com HTML e CSS, reproduzindo o layout de uma tela
de acesso a uma plataforma de alunos. Feita como exercício da disciplina de
desenvolvimento web.

## Sobre o projeto

O objetivo foi montar um formulário de login e estilizá-lo para que a caixa
fique centralizada na tela, com cantos arredondados e sombra. A página contém:

- Logo e nome da plataforma
- Título principal
- Campo para E-mail ou Usuário
- Campo para Senha
- Link de recuperação de senha
- Botão "Entrar"
- Link para cadastro

## Tecnologias

- HTML5
- CSS3 (Flexbox para centralizar a caixa)

## Estrutura de arquivos

```
atividade1-login/
├── index.html
├── style.css
└── README.md
```

## Como executar

1. Baixe os arquivos e mantenha os três na mesma pasta.
2. Abra o arquivo `index.html` com um duplo clique (ele abre no navegador).

Não precisa de servidor nem de nenhuma instalação.

## Detalhes de estilo

- Fundo cinza claro: `#f0f2f5`
- Botão verde: `#28a745`
- Caixa branca centralizada com `border-radius` e `box-shadow`
